# Application Development Requirements & Implementation Roadmap
**Target Artifact:** `app/index.html` & Backend Integration  
**Core Framework:** Autonomous Data-to-Decision Agent System (Skills 01–37)

## 2. Required UI Components for `app/index.html`

### A. Authentication & Tenant Selector Bar (Skill 31)
* **JWT Token State:** Displays active session status, logged-in user name, and role (`Admin`, `Analyst`, `Executive`).
* **Multi-Tenant Dropdown:** Selects active `tenant_id` to isolate dataset queries and reports.
* **Security Guard:** Redirects unauthenticated requests to the modal login screen.

### B. Real-Time Agent Reasoning Console (Skill 33)
* **SSE Event Stream Listener:** Displays live execution logs from Agents A0–A7 as they process tasks.
* **DAG Progress Indicator:** Visual pipeline tracker showing current step status (*In-Progress*, *Completed*, *Failed*).
* **Thought Inspection Modal:** Expandable view to inspect raw LLM reasoning and system prompts.

### C. Governed RAG KPI Scorecard Strip (Skills 16, 28, 30)
* **Traffic-Light Cards:** Visual indicators (**RED**, **AMBER**, **GREEN**) for core financial/operational KPIs.
* **Metric Details:** Displays actual value, target/budget, percentage variance, and trend arrow indicators.
* **BLUF Banner:** Executive summary card providing Bottom-Line Up Front commentary generated by Agent A6.

### D. Interactive Data-Ink Visualizations (Skills 22, 27, 33)
* **Variance Waterfall Bridge:** Visual step chart breaking down budget vs. actual variances across key cost drivers.
* **Fan Chart (Forecast Horizons):** Time-series plot displaying historical actuals alongside P10, P50, and P90 forecast intervals.
* **Tornado Sensitivity Diagram:** Ranked bar visual showing variable impacts on Expected Cost at Completion (EAC).

### E. Human-in-the-Loop (HITL) Action Approval Table (Skills 24, 34)
* **Action Candidate Pool:** Data table listing proposed corrective actions with estimated recovery amount, cost, and feasibility score.
* **Status Badges:** `Draft`, `Pending Approval`, `Approved`, `Rejected`, `Executed`.
* **Action Buttons:** One-click **Approve**, **Reject**, or **Override Parameters** triggers requiring reviewer notes.

### F. System Health & Gemini Quota Footer (Skills 36, 37)
* **Gemini API Monitor:** Real-time counter of total token consumption, active rate limit status, and estimated API cost.
* **SQLite Database Health:** Indicator for database WAL status, active connection pool, and storage utilization.

## 3. Backend API Gateway Requirements (`app/main.py`)

To serve `app/index.html`, the backend server requires the following REST and streaming endpoints:

| Endpoint | Method | Purpose | Related Skills |
| :--- | :--- | :--- | :--- |
| `/api/v1/auth/login` | `POST` | Authenticates user credentials and issues JWT bearer tokens | Skill 31 |
| `/api/v1/auth/me` | `GET` | Validates active session and returns user permissions & tenant list | Skill 31 |
| `/api/v1/tasks/run` | `POST` | Triggers Orchestrator DAG execution over target dataset | Skills 01–30 |
| `/api/v1/stream` | `GET` | Server-Sent Events (SSE) endpoint streaming real-time agent execution logs | Skill 33 |
| `/api/v1/dashboard/kpis` | `GET` | Retrieves calculated KPIs, variance drivers, and status RAG indicators | Skills 11, 12, 16 |
| `/api/v1/approvals` | `GET` / `POST` | Fetches pending action proposals and submits manager approval decisions | Skill 34 |
| `/api/v1/system/health` | `GET` | Returns SQLite health metrics, database size, and Gemini token usage | Skills 36, 37 |

## 4. SQLite Database Schema Requirements (`control.sqlite`)

The database backend requires specific relational tables to support user access, job queuing, approval state, and system auditing:

```sql
-- 1. Tenant & User Access Control (Skill 31)
CREATE TABLE tenants (
    tenant_id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE users (
    user_id TEXT PRIMARY KEY,
    email TEXT UNIQUE NOT NULL,
    password_hash TEXT NOT NULL,
    role TEXT NOT NULL CHECK(role IN ('admin', 'analyst', 'executive', 'reviewer'))
);

CREATE TABLE tenant_users (
    tenant_id TEXT REFERENCES tenants(tenant_id),
    user_id TEXT REFERENCES users(user_id),
    PRIMARY KEY (tenant_id, user_id)
);

-- 2. Async Job Queue (Skill 35)
CREATE TABLE job_queue (
    job_id TEXT PRIMARY KEY,
    tenant_id TEXT NOT NULL,
    task_type TEXT NOT NULL,
    payload_json TEXT NOT NULL,
    status TEXT DEFAULT 'pending' CHECK(status IN ('pending', 'processing', 'completed', 'failed')),
    error_message TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 3. Human-in-the-Loop Action Approvals (Skill 34)
CREATE TABLE candidate_actions (
    action_id TEXT PRIMARY KEY,
    tenant_id TEXT NOT NULL,
    title TEXT NOT NULL,
    category TEXT NOT NULL,
    estimated_impact REAL NOT NULL,
    implementation_days INT NOT NULL,
    status TEXT DEFAULT 'pending_review' CHECK(status IN ('draft', 'pending_review', 'approved', 'rejected', 'executed')),
    reviewed_by TEXT REFERENCES users(user_id),
    review_notes TEXT,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 4. Gemini Token Consumption & Governance (Skill 36)
CREATE TABLE gemini_token_logs (
    log_id INTEGER PRIMARY KEY AUTOINCREMENT,
    tenant_id TEXT NOT NULL,
    model_name TEXT NOT NULL,
    prompt_tokens INT NOT NULL,
    completion_tokens INT NOT NULL,
    total_tokens INT NOT NULL,
    estimated_cost_usd REAL NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 5. Audit Trail & System Events (Skill 37)
CREATE TABLE audit_trail (
    event_id INTEGER PRIMARY KEY AUTOINCREMENT,
    tenant_id TEXT NOT NULL,
    user_id TEXT,
    trace_id TEXT NOT NULL,
    action TEXT NOT NULL,
    details_json TEXT,
    timestamp TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```
